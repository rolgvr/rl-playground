Connect your worker

Everything runs on your machine, not our servers — the whole platform computes on your worker. Your GPU, your models and your API keys never leave it; we only serve this page.

The worker is open and free to download — no account, no access request.

  1. Get the worker. Clone the public repo and install: 
    git clone github.com/rolgvr/rl-playground.git
cd rl-playground
pip install -e .
  2. Start it, pointed at this site 
    rl-playground --mode worker --allow-origin https://rl.safezoneaitech.com
  3. Paste the pairing token it prints
    My worker is on a different port

University (a Dean designs a curriculum, then teaches the model each subject to mastery)

How the University works — start here
  1. Model to teach — a name for your student model. Skills it masters are saved under this name (reusable later).
  2. Domain — what it should become expert in (e.g. "reinforcement learning"). The Dean (the API teacher) turns this into an ordered curriculum of subjects.
  3. Mastery target — how good is "good enough" per subject: the teacher-judged win-rate the student must reach on a subject's exam before moving on.
  4. Subjects — leave at 0 to let the Dean decide how many subjects the domain truly needs. Caps: it runs autonomously and stops at max minutes / budget ($) (and Subjects if you set one). Press Stop anytime.
  5. Press Enrol & teach. For each subject it: 🧑‍🏫 writes in-depth Q&A → 🏋️ trains the student → ✍️ runs an exam (you'll see the loop light up per question) → 🎓 records mastery. The Dean re-teaches weak subjects.
  6. Watch the syllabus bars fill, then use Model & skills (right) to turn any learned skill on/off or retrain it, and Test this model (below) to chat with your graduate.

No API key? It runs a local stand-in (weaker, free) so you can see the whole flow. Set a real key in Teach LLM for genuine depth.

Train a game agent

Pick a game and a deep-RL algorithm, tune its hyperparameters, and train it on your GPU. Each learns to play from the raw screen.

Rough timing on a good GPU: Pac-Man ≈ 0.1s/episode (300 ≈ 30s, clears most pellets), Pong ≈ 0.4s/episode (150 ≈ 1 min, wins most games — rallies make its episodes longer). More episodes → better play.

How to build a graph
  1. Click a behaviour below to drop an agent node on the canvas.
  2. Drag from a node's right dot (output) to another's left dot (input) to connect them.
  3. A critic has two outputs: ✓ pass and ✗ fail. Wire fail → Refiner, then the Refiner back to the critic to make a refine loop.
  4. Edit each node's prompt and pick its model (local Qwen or teacher API).
  5. Type a question and press ▶ Run graph — watch the trace below.

Legend
  • Question / Answer — graph start & end
  • Generator / Refiner — write & improve answers
  • Critics / Verifier — judge (score 1–5); have ✓ pass / ✗ fail outputs
  • Self-consistency — sample several, keep the best
  • Yellow dots = ports — drag output → input to connect
